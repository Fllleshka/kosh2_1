# 🏅 Kosh Sports Bot

Telegram-бот спортивного сообщества **[Kosh Sports](https://t.me/koshsports)**. Он помогает спортсменам находить тренеров и партнёров для тренировок, а тренерам — учеников. Пользователь регистрирует анкету через пошаговый диалог, а потом листает чужие анкеты и связывается с понравившимися людьми прямо в Telegram.

> Бот написан на асинхронном **aiogram 3** и хранит данные в **SQLite** через **SQLAlchemy 2**.

## 📲 Как найти бота

| Способ | Ссылка |
|---|---|
| Прямая ссылка | **https://t.me/KoshTestBot** *(замените на реальный username)* |
| Поиск в Telegram | Введите **@KoshTestBot* в строке поиска |
| Telegram-канал сообщества | https://t.me/koshsports |

Чтобы начать, нажмите **«Начать»** или отправьте команду `/start`.

## ✨ Возможности

### Для пользователей

- **Регистрация анкеты** через пошаговый диалог (машина состояний FSM): имя, фамилия, отчество, дата рождения, город, вид спорта, уровень подготовки, место тренировок, роль (тренер или спортсмен), фото и описание. Перед сохранением данные показываются на проверку.
- **Поиск тренера** и **поиск партнёра для занятий** — карусель анкет с кнопками «назад» и «вперёд», с рейтингом и ссылкой на профиль в Telegram. Собственная анкета в выдачу не попадает.
- **Редактирование профиля** — любое поле меняется отдельно через inline-кнопки, в том числе фото и описание.
- **«Мой аккаунт» и «Мой профиль для других»** — проверка регистрации и просмотр своей анкеты в том виде, как её видят другие.
- **Соревнования** — ссылка на таблицу соревнований (Google Sheets).
- **Справка**: `/help` — связь с техническим специалистом, `/helpfounder` — связь с основателями сообщества.

### Для администраторов (`/admin`)

- **Сохранить копию БД** — резервная копия базы с отметкой времени.
- **Все тренеры** и **Все спортсмены** — выгрузка отформатированного Excel-отчёта (`.xlsx`) прямо в чат.

### Справочники

Справочники в базе при первом запуске заполняются автоматически: 18 городов, 18 видов спорта (бег, футбол, бокс, плавание, шахматы, киберспорт и другие), 3 уровня подготовки, 4 типа мест тренировок, роли пользователей. Для демонстрации поиска создаётся 200 тестовых анкет, их генерирует Faker с русской локалью.

## 🛠 Технологии

| Назначение | Инструмент |
|---|---|
| Telegram-бот | [aiogram 3](https://docs.aiogram.dev/) (роутеры, FSM, inline- и reply-клавиатуры) |
| База данных | SQLite + [SQLAlchemy 2](https://www.sqlalchemy.org/) (декларативные модели `Mapped`) |
| Конфигурация | [python-decouple](https://pypi.org/project/python-decouple/) (переменные окружения из `.env`) |
| Тестовые данные | [Faker](https://faker.readthedocs.io/) (`ru_RU`) |
| Отчёты | [openpyxl](https://openpyxl.readthedocs.io/) |
| Асинхронность | `asyncio`, long polling |

## 🗄 Модель данных

```
users ──┬── town           (город)
        ├── kind_sport     (вид спорта)
        ├── level_training (уровень подготовки)
        ├── accaunt_type   (роль: тренер / спортсмен / администратор)
        └── place          (место тренировок)
```

Таблица `users` хранит ФИО, дату рождения, рейтинг, Telegram ID, описание и внешние ключи на пять справочников.

## 🚀 Установка и запуск

### 1. Клонирование и зависимости

```bash
git clone https://github.com/Fllleshka/kosh2_1.git
cd kosh2_1

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt openpyxl
```

### 2. Настройка `.env`

Создайте в корне проекта файл `.env`:

```env
# Токен бота от @BotFather
TOKEN=123456:ABC-DEF...

# Telegram ID администраторов (числа)
FOUNDER1TELEGRAMID=
FOUNDER2TELEGRAMID=
TECHNICALSPRCTELEGRAMID=

# Ссылки для кнопок справки (например, https://t.me/username)
TECHNICALSPRC=
FOUNDER1=
FOUNDER2=
NAMEFOUNDER1=
NAMEFOUNDER2=

# Ссылка на таблицу соревнований
googlesheetcompetitiontable=
```

**Как получить токен:** напишите [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и username (он должен оканчиваться на `bot`) и скопируйте выданный токен. Свой Telegram ID можно узнать у бота [@userinfobot](https://t.me/userinfobot).

### 3. Служебные папки

Создайте папки, в которые бот сохраняет файлы:

```bash
mkdir -p database/images/users database/backups database/files
```

### 4. Запуск

```bash
python aiogram_run.py
```

Если файла базы `database/my_database.db` нет, бот создаст его и заполнит справочники и тестовые анкеты.

## 🧭 Как это работает

1. `aiogram_run.py` подключает роутеры: старт, регистрация, команды, поиск, редактирование, администрирование.
2. Диалоги регистрации и редактирования построены на состояниях FSM: ответ пользователя сохраняется в `state`, а в базу данные попадают только после подтверждения.
3. Поиск строит список анкет по роли и показывает их по одной. Индексы соседних анкет передаются в `callback_data`, поэтому карусель работает без хранения состояния на сервере.
4. Администраторские функции формируют `.xlsx` через openpyxl и отправляют его документом.
